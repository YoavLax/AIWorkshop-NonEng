# Glossary

| Word | Plain meaning |
|------|---------------|
| **AI / LLM** | A program trained on lots of text that predicts helpful replies. "LLM" = large language model. |
| **Prompt** | The message you give the AI. |
| **Context** | Everything the AI can see right now: your prompt, attached files, saved rules. |
| **Hallucination** | A confident answer that is invented or wrong. |
| **Ask / Plan / Agent** | Modes: answer / plan / do. |
| **Agent** | AI that carries out multi-step work using tools (reads and creates files, checks its own work). |
| **Tool** | An action the agent may use, such as reading or creating a file. |
| **Instructions** | A file of house rules Copilot follows in every chat. |
| **Prompt file** | A saved, reusable prompt you start with `/`. |
| **Custom agent** | A saved specialist persona with its own rules. |
| **Skill** | A folder with a playbook and templates that Copilot loads when it fits your request. |
| **MCP** | A standard "plug" that connects Copilot to other tools or systems (for example Jira or a database). |
| **Markdown (`.md`)** | Simple formatted text file. The rules and docs here use it. |
| **CSV** | A spreadsheet saved as plain text. Opens in Excel. |
| **HTML file** | A web page in a single file; opens in your browser. |
| **Dashboard** | A page of key numbers and charts. |
| **Repository (repo)** | A project folder tracked by Git. |
| **Git** | A tool that remembers every version of your files. |
| **Commit** | A named save point you can return to. |
| **Clone** | Download a copy of a repository to your computer. |
| **Branch / worktree** | A separate copy of the files to work in safely; the Copilot app uses one per session. |
| **Pull request (PR)** | A proposal to merge changes; people review it before it is accepted. |
| **Issue** | A task or request written down on GitHub. |
| **Cloud agent** | A Copilot agent that works on GitHub's servers and returns a pull request. |
| **eNPS** | Employee Net Promoter Score: % promoters (9-10) minus % detractors (0-6). |
| **Attrition rate** | Leavers in a period divided by average headcount in that period. |
| **Raw vs. adjusted pay gap** | Raw compares all averages; adjusted compares people at the same level and role. |
