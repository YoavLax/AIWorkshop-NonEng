# Solutions (peek only if you are stuck)

Try each exercise on your own first. These files are here so nobody is blocked.

| File | What it is | Module |
|------|-----------|--------|
| `headcount-dashboard.html` | Finished headcount dashboard. Open it and choose `data/employees.csv`. | 4.2 |
| `attrition-dashboard.html` | Attrition dashboard. Choose `data/employees.csv` **and** `data/exit_interviews.csv` together. | 4.4A |
| `customization/copilot-instructions.md` | House rules (copy to `.github/copilot-instructions.md`) | 5.2 |
| `customization/prompts/` | Prompt files (copy to `.github/prompts/`) | 5.3 |
| `customization/agents/` | Custom agents (copy to `.github/agents/`) | 5.4 |
| `customization/skills/hr-dashboard-builder/` | The dashboard skill and its template (copy to `.github/skills/`) | 5.5 |

Dashboards in this folder load the chart library from `../assets/vendor/`, so keep them where they are, or copy them into `output/` (same depth).

Remember: the goal is not to have a dashboard. It is to learn how to **ask, plan, check and improve**.
